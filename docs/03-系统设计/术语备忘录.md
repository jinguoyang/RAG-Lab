## SubjectSearchDropdown — 主体搜索下拉框

**位置：** `frontend/src/app/components/rag/SubjectSearchDropdown.tsx`

**用途：** 统一的用户/用户组搜索选择组件，替代各页面内联的搜索逻辑。

**交互行为：**
- 聚焦输入框即展示全部可选主体（最多 8 条）
- 输入关键词后 200ms 防抖，调用后端 API 模糊搜索
- 点击选项即选中，自动关闭下拉框并回填输入框
- 已添加的主体（由 `excludedIds` 控制）显示为禁用态 + 提示文字

**加载态：** 请求中显示旋转动画 + "搜索中..." 文字，避免误判为"暂无数据"。

**调用方：**
- P04 用户组管理 — 添加组成员
- P19 文档库成员管理 — 添加文档库成员

**Props：**

| Prop | 类型 | 说明 |
|---|---|---|
| `subjectType` | `"user" \| "group"` | 搜索主体类型 |
| `onSelect` | `(subjectId, label) => void` | 选中回调 |
| `excludedIds` | `Set<string>` | 已添加的 ID 集合，对应选项禁用 |
| `excludedLabel` | `string` | 禁用态提示文字，默认"已是成员" |
| `placeholder` | `string` | 输入框占位文字 |
| `disabled` | `boolean` | 是否禁用整个组件 |
| `inputClassName` | `string` | 输入框自定义样式类 |

## UnderlineTabs — 下划线标签页

**位置：** `frontend/src/app/components/rag/UnderlineTabs.tsx`

**用途：** 统一的下划线风格标签页组件，封装 Radix Tabs 原语并预设项目视觉样式，替代各页面内联的 tabs 样式代码。

**视觉风格：**
- 标签栏底部横线分隔（`border-b border-border-cream`）
- 激活态标签显示赤陶色下划线（`text-terracotta` + `border-b-2 border-terracotta`）
- 未激活标签为灰色（`text-stone-gray`），悬停变深（`hover:text-near-black`）

**导出组件：**

| 组件 | 说明 |
|---|---|
| `UnderlineTabs` | 根容器，对应 `Tabs.Root` |
| `UnderlineTabsList` | 标签栏，对应 `Tabs.List` |
| `UnderlineTabsTrigger` | 单个标签触发器，对应 `Tabs.Trigger` |
| `UnderlineTabsContent` | 标签内容面板，对应 `Tabs.Content` |

**调用方：**
- P07 文档详情 — 版本 / Chunks / 入库作业 / 索引同步作业
- P16 文档库详情 — 概览 / 源文件版本 / 解析版本 / 预览 / 使用影响
- P10 QA 历史 — 运行记录 / 观测概览 / 评估批次

## DocumentListLayout — 通用文档列表布局

**位置：** `frontend/src/app/components/rag/DocumentListLayout.tsx`

**用途：** 通用的文档列表布局组件，提供搜索、筛选、批量操作、表格、分页的统一样式和交互。适用于文档中心、文档库文档列表等场景。

**视觉风格：**
- 搜索栏：输入框 + 搜索按钮 + 状态筛选下拉框
- 批量操作栏：圆角卡片样式（`rounded-xl border border-border-cream bg-ivory p-4`）
- 表格：带边框的圆角容器
- 分页：左侧显示总数，右侧显示翻页按钮

**导出组件：**

| 组件 | 说明 |
|---|---|
| `DocumentListLayout` | 通用文档列表布局组件 |

**Props：**

| Prop | 类型 | 说明 |
|---|---|---|
| `search` | `SearchConfig` | 搜索配置（placeholder、value、onChange、onSearch） |
| `statusFilter` | `StatusFilterConfig` | 状态筛选配置（value、onChange、options） |
| `headerExtra` | `ReactNode` | 右侧额外内容（如统计信息） |
| `batch` | `BatchConfig` | 批量操作配置（selectedCount、actions、loading） |
| `columns` | `TableColumn[]` | 表格列配置（key、label、className） |
| `data` | `unknown[]` | 表格数据 |
| `loading` | `boolean` | 是否正在加载 |
| `emptyMessage` | `string` | 空状态提示 |
| `emptyIcon` | `ReactNode` | 空状态图标 |
| `renderRow` | `(item, index) => ReactNode` | 渲染表格行 |
| `pagination` | `PaginationConfig` | 分页配置（total、pageNo、totalPages、onPageChange） |
| `showSelectAll` | `boolean` | 是否显示全选复选框 |
| `selectAllChecked` | `boolean` | 全选状态 |
| `onSelectAll` | `(checked: boolean) => void` | 全选回调 |
| `selectedIds` | `Set<string>` | 选中的 ID 集合 |
| `getRowId` | `(item: unknown) => string` | 获取行 ID |
| `onSelectionChange` | `(ids: Set<string>) => void` | 选中状态变化回调 |

**调用方：**
- P06 文档中心 — 文档列表
- P18 文档库文档列表

**使用示例：**

```tsx
<DocumentListLayout
  search={{
    placeholder: "按文档名搜索...",
    value: searchTerm,
    onChange: setSearchTerm,
    onSearch: handleSearch,
  }}
  statusFilter={{
    value: statusFilter,
    onChange: setStatusFilter,
    options: [
      { value: "", label: "全部状态" },
      { value: "active", label: "正常" },
      { value: "disabled", label: "已停用" },
    ],
  }}
  batch={{
    selectedCount: selectedIds.size,
    actions: [
      { label: "重新治理", icon: <RefreshCw className="w-4 h-4" />, onClick: handleReparse },
      { label: "删除", icon: <Trash2 className="w-4 h-4" />, variant: "destructive", onClick: handleDelete },
    ],
  }}
  columns={[
    { key: "name", label: "文档名" },
    { key: "status", label: "状态", className: "w-20" },
    { key: "updatedAt", label: "更新时间", className: "w-36" },
  ]}
  data={documents}
  loading={loading}
  emptyMessage="暂无文档"
  renderRow={(doc) => (
    <>
      <TableCell>{doc.name}</TableCell>
      <TableCell><StatusBadge status={doc.status} /></TableCell>
      <TableCell>{doc.updatedAt}</TableCell>
    </>
  )}
  pagination={{
    total: documentTotal,
    pageNo,
    totalPages,
    onPageChange: handlePageChange,
  }}
  showSelectAll
  selectAllChecked={selectedIds.size === documents.length}
  onSelectAll={handleSelectAll}
  selectedIds={selectedIds}
  getRowId={(doc) => doc.id}
  onSelectionChange={setSelectedIds}
/>
```

## 术语速查

| 术语 | 含义 |
|---|---|
| 主体（Subject） | 权限系统中的被授权对象，分为 `user`（用户）和 `group`（用户组） |
| 文档库（Library） | 文档的顶层容器，成员权限独立于知识库 |
| 知识库（Knowledge Base） | 检索和问答的工作单元，绑定文档库后才能检索 |
| 绑定（Binding） | 将文档库关联到知识库的动作 |
