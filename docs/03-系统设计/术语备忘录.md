## SubjectSearchDropdown — 主体搜索下拉框

**位置：** `frontend/src/app/components/rag/SubjectSearchDropdown.tsx`

**用途：** 统一的用户/用户组搜索选择组件，替代各页面内联的搜索逻辑。

**交互行为：**
- 聚焦输入框即展示全部可选主体（最多 8 条）
- 输入关键词后 200ms 防抖，调用后端 API 模糊搜索
- 点击选项即选中，自动关闭下拉框并回填输入框
- 已添加的主体（由 `excludedIds` 控制）显示为禁用态 + 提示文字

**加载态：** 请求中显示旋转动画 + "搜索中..." 文字，避免误判为"暂无数据"。

**调用方：**
- P04 用户组管理 — 添加组成员
- P19 文档库成员管理 — 添加文档库成员

**Props：**

| Prop | 类型 | 说明 |
|---|---|---|
| `subjectType` | `"user" \| "group"` | 搜索主体类型 |
| `onSelect` | `(subjectId, label) => void` | 选中回调 |
| `excludedIds` | `Set<string>` | 已添加的 ID 集合，对应选项禁用 |
| `excludedLabel` | `string` | 禁用态提示文字，默认"已是成员" |
| `placeholder` | `string` | 输入框占位文字 |
| `disabled` | `boolean` | 是否禁用整个组件 |
| `inputClassName` | `string` | 输入框自定义样式类 |

## UnderlineTabs — 下划线标签页

**位置：** `frontend/src/app/components/rag/UnderlineTabs.tsx`

**用途：** 统一的下划线风格标签页组件，封装 Radix Tabs 原语并预设项目视觉样式，替代各页面内联的 tabs 样式代码。

**视觉风格：**
- 标签栏底部横线分隔（`border-b border-border-cream`）
- 激活态标签显示赤陶色下划线（`text-terracotta` + `border-b-2 border-terracotta`）
- 未激活标签为灰色（`text-stone-gray`），悬停变深（`hover:text-near-black`）

**导出组件：**

| 组件 | 说明 |
|---|---|
| `UnderlineTabs` | 根容器，对应 `Tabs.Root` |
| `UnderlineTabsList` | 标签栏，对应 `Tabs.List` |
| `UnderlineTabsTrigger` | 单个标签触发器，对应 `Tabs.Trigger` |
| `UnderlineTabsContent` | 标签内容面板，对应 `Tabs.Content` |

**调用方：**
- P07 文档详情 — 版本 / Chunks / 处理作业
- P16 文档库详情 — 概览 / 源文件版本 / 解析版本 / 预览 / 使用影响
- P10 QA 历史 — 运行记录 / 观测概览 / 评估批次

## DocumentListLayout — 文档列表布局

**位置：** `frontend/src/app/components/rag/DocumentListLayout.tsx`

**用途：** 统一文档类列表的搜索、筛选、批量操作、加载/空态和分页布局，避免 P06 文档中心与 P18 文档库文档列表在工具栏、按钮样式和分页信息上各自实现。

**设计边界：**
- 组件只负责列表外壳，不理解文档中心或文档库的业务字段。
- 表格列、表格行和行内操作由调用页面通过 `children` 提供。
- 搜索按钮、筛选下拉、批量操作条和分页统一使用文档库列表的紧凑后台样式。
- 不在顶部搜索栏额外展示“共 N 条，当前页 N 条”，总数统一放在分页区。

**主要 Props：**

| Prop | 类型 | 说明 |
|---|---|---|
| `search` | `SearchConfig` | 搜索占位文案、当前值、输入变化和搜索回调 |
| `statusFilter` | `StatusFilterConfig` | 状态筛选值、选项和变化回调 |
| `batch` | `BatchConfig` | 已选数量、批量操作按钮和批量加载状态 |
| `itemCount` | `number` | 当前列表项数量，用于决定显示空态还是表格 |
| `loading` | `boolean` | 是否显示统一加载态 |
| `emptyState` | `ReactNode` | 页面自定义空态内容 |
| `pagination` | `PaginationConfig` | 总数、页码、总页数和翻页回调 |
| `children` | `ReactNode` | 页面自有表格内容 |

**调用方：**
- P06 文档中心 — 已绑定文档列表
- P18 文档库文档列表 — 源文件列表

## 术语速查

| 术语 | 含义 |
|---|---|
| 主体（Subject） | 权限系统中的被授权对象，分为 `user`（用户）和 `group`（用户组） |
| 文档库（Library） | 文档的顶层容器，成员权限独立于知识库 |
| 知识库（Knowledge Base） | 检索和问答的工作单元，绑定文档库后才能检索 |
| 绑定（Binding） | 将文档库关联到知识库的动作 |
