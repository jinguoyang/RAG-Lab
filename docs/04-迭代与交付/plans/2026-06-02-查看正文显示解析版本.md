# 修复"查看正文"按钮显示解析版本

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复文档库详情页"解析版本"tab 中"查看正文"按钮的行为，使其显示解析后的 md 文件内容，而不是跳转到预览查看源文件。

**Architecture:** 修改 `P16_LibraryDetail.tsx` 中 preview tab 的条件判断逻辑，将 `selectedParseRevision` 的判断优先级提前，确保用户点击"查看正文"时优先显示解析后的文本内容。

**Tech Stack:** React, TypeScript

---

## 问题分析

### 当前行为
1. 用户在"解析版本"tab 点击"查看正文"按钮
2. 按钮设置 `selectedParseRevisionId` 并切换到 "preview" tab
3. preview tab 根据源文件类型（`previewType`）判断显示什么：
   - PDF → 显示 `PdfPreview`（源文件预览）
   - DOCX → 显示 `DocxPreview`（源文件预览）
   - Markdown/Text 或有 selectedParseRevision → 显示 `TextPreview`

### 问题
当源文件是 PDF 或 DOCX 时，即使用户点击了"查看正文"，仍然显示源文件预览，而不是解析后的文本内容。

### 期望行为
点击"查看正文"应该始终显示解析后的 md 文件内容，无论源文件是什么格式。

</UnderlineTabsContent>
