# 章节级交互式课程蓝图实施计划

> **执行要求：** 按测试驱动方式逐项实施；每个行为先补失败测试，再写最小实现。步骤使用复选框跟踪。

**目标：** 将员工课堂从多 Chunk 临场改写升级为整篇理解、章节脚本授课、受控对话互动和可恢复连续学习。

**架构：** 计划生成阶段读取入选文档的完整有效内容，按章节聚合后生成课程蓝图与 `teachingScript`；课堂直接使用冻结脚本，Chunk 仅保留为 Citation 与追问证据。现有课堂状态机、进度表和 ex-app 会话镜像继续作为流程与恢复基础。

**技术栈：** FastAPI、Pydantic、SQLAlchemy、现有 LLM Client、Pytest、React、TypeScript、Vite。
