# 查看正文改为弹窗展示解析版本

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将"查看正文"按钮的行为从跳转 preview tab 改为在解析版本 tab 内以弹窗形式展示解析后的 md 内容，同时恢复 preview tab 的源文件预览功能。

**Architecture:** 在 `P16_LibraryDetail.tsx` 中添加一个 Dialog 状态和组件，点击"查看正文"时打开弹窗显示 `TextPreview`；同时恢复 preview tab 的原始条件判断逻辑（基于源文件类型）。

**Tech Stack:** React, TypeScript, Radix UI Dialog

---

## 文件结构

- Modify: `frontend/src/app/pages/P16_LibraryDetail.tsx`

  - 修改"查看正文"按钮行为（打开弹窗而非切换 tab）
  - 恢复 preview tab 原始条件逻辑
  - 添加解析正文弹窗 JSX

## Task 1: 修改 P16_LibraryDetail.tsx

**Files:**
- Modify: `frontend/src/app/pages/P16_LibraryDetail.tsx`

- [ ] **Step 1: 添加 Dialog 导入**

在文件顶部导入区域添加 Dialog 组件：

```tsx
// 第 10 行附近，现有导入之后添加

```

- [ ] **Step 2: 添加弹窗状态**

在组件内部的状态声明区域（约第 80-90 行附近）添加：

```tsx
const [previewParseRevision, setPreviewParseRevision] = useState<string | null>(null);
```

- [ ] **Step 3: 修改"查看正文"按钮行为**

将解析版本表格中的"查看正文"按钮从切换 tab 改为打开弹窗：

```tsx
// 当前代码
<Button variant="ghost" size="sm" title="查看正文" onClick={() => { setSelectedParseRevisionId(revision.parseRevisionId); setActiveTab("preview"); }}>
  <Eye className="h-4 w-4" />
</Button>

// 改为
<Button variant="ghost" size="sm" title="查看正文" onClick={() => setPreviewParseRevision(revision.parseRevisionId)}>
  <Eye className="h-4 w-4" />
</Button>
```

- [ ] **Step 4: 恢复 preview tab 原始条件逻辑**

将 preview tab 的条件判断恢复为基于源文件类型：

```tsx
// 当前代码（有 selectedParseRevision 判断在前）
<UnderlineTabsContent value="preview" className="space-y-6 outline-none">
  {selectedParseRevision ? (
    <TextPreview documentId={docId} parseRevisionId={selectedParseRevision.parseRevisionId} />
  ) : previewType === "pdf" ? (
    ...
  ) : previewType === "docx" ? (
    ...
  ) : previewType === "markdown" || previewType === "text" ? (
    <TextPreview documentId={docId} />
  ) : (
    ...
  )}
</UnderlineTabsContent>

// 恢复为
<UnderlineTabsContent value="preview" className="space-y-6 outline-none">
  {previewType === "pdf" ? (
    <PdfPreview documentId={docId} fileName={doc.name} />
  ) : previewType === "docx" ? (
    <Suspense fallback={<Alert variant="info" title="正在加载 DOCX 预览器" message="首次打开 DOCX 预览时需要加载解析组件。" />}>
      <DocxPreview documentId={docId} />
    </Suspense>
  ) : previewType === "markdown" || previewType === "text" ? (
    <TextPreview documentId={docId} />
  ) : (
    <div className="rounded-lg border border-border-cream bg-ivory py-12 text-center">
      <FileText className="mx-auto mb-4 h-12 w-12 text-stone-gray" />
      <p className="text-stone-gray">暂不支持此文件格式的在线预览</p>
    </div>
  )}
</UnderlineTabsContent>
```

- [ ] **Step 5: 添加解析正文弹窗 JSX**

在页面底部（其他 Drawer 附近）添加 Dialog 组件：

```tsx
<Dialog open={!!previewParseRevision} onOpenChange={(open) => { if (!open) setPreviewParseRevision(null); }}>
  <DialogContent className="max-w-4xl max-h-[80vh] overflow-hidden flex flex-col">
    <DialogHeader>
      <DialogTitle>解析正文</DialogTitle>
    </DialogHeader>
    <div className="flex-1 overflow-auto">
      {previewParseRevision && (
        <TextPreview documentId={docId} parseRevisionId={previewParseRevision} />
      )}
    </div>
  </DialogContent>
</Dialog>
```
