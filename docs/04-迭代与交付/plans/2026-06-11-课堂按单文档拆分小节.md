# 课堂按单文档拆分小节实施计划

> **执行要求：** 按 TDD 顺序逐项实施，先验证失败，再做最小修复。

**目标：** 学习指定 `documentId` 时，小节生成、课堂摘要、进度和证据都只属于该文档。

**架构：** 计划生成阶段按文档分别调用 LLM，避免多文档上下文影响单文档小节设计。应用端创建课堂时先裁剪冻结快照，平台端再依据 `inputs.documentId` 过滤文档和小节，形成双重边界。

**技术栈：** Python 3.12、FastAPI、SQLAlchemy、Pydantic、pytest。
