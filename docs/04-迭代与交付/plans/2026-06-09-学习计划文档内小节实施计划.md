# 学习计划文档内小节实施计划

> **供 Agent 执行：** 按任务逐项实施并使用复选框跟踪；功能修改遵循测试先行，完成前执行完整验证。

**目标：** 将学习计划调整为 `documents[].sections[]` 嵌套结构，并让课堂按文档顺序和文档内小节顺序执行。

**架构：** 平台生成并校验文档内小节，ex-app 将完整嵌套文档作为本地业务真值保存，课堂入口只接收嵌套文档快照。平台课堂在内部统一展平执行序列，并为每个小节补充父级文档信息。

**技术栈：** Python 3.12、FastAPI、Pydantic、SQLAlchemy、Pytest、React 19、TypeScript、Vite。
