# Epic 总览

Epic 是能力域，不是时间盒。本文只保留 Epic 的概念口径和版本归属索引；具体 Backlog、优先级和状态以 [产品待办清单](../产品待办清单.md) 为准。

## 1. 与其他对象的关系

| 对象 | 作用 | 维护位置 |
| --- | --- | --- |
| Epic | 表示能力域，承接一组 Backlog | [产品待办清单](../产品待办清单.md) |
| Backlog | 最小可跟踪交付项 | [产品待办清单](../产品待办清单.md) |
| Sprint | 时间盒和执行记录 | [Sprint 总览](../sprints/README.md) |
| Release | 发布范围、验收和风险判断 | [Release 总览](../releases/README.md) |

## 2. 当前 Epic 状态

- E0 至 E22 均已完成。
- 最新能力域是 E22 知识库治理工作流强化，对应内部增强和 Sprint 27 至 Sprint 29。
- 后续新增能力域时，先在产品待办清单中增加 Epic 和 Backlog，再按需要补充 Sprint 或 Release 计划。

## 3. 版本归属索引

| 版本 | Epic 范围 | 说明 |
| --- | --- | --- |
| V1.0 | E0-E12 | 最小闭环、权限治理、验收硬化和参数生效 |
| V1.1 | E12-E13 | 质量回归、批量评估和配置优化闭环 |
| V1.2 | E14-E15 | Provider 生产化接入、知识库治理和文档质量 |
| V1.3 | E16-E17 | 稳定性观测、协作治理和权限解释 |
| V1.4 | E18 | 真实入库、多副本构建和 LLM / Embedding API 契约 |
| V1.5 | E19 | 真实检索、生成、回放复跑和差异对比 |
| V1.6 | E20 | 真实文档 RAG 端到端闭环 |
| V1.7 | E21 | RAG 模块化调优、参数快照和评估对比 |
| 内部增强 | E22 | 知识库治理工作流、诊断可操作化和治理后验证 |

## 4. 维护规则

- 本文件不再重复维护完整 Epic 状态表。
- Epic 状态、Backlog 编号、优先级和负责人统一在 [产品待办清单](../产品待办清单.md) 中维护。
- 单个 Epic 的验证说明可以保留在本目录；若内容已过期，应标注为历史验证说明，而不是复制到多个入口。
