Release 面向版本发布，汇总跨 Epic、跨 Sprint 的交付范围、验收状态、环境要求和遗留风险。

本文是 Release 状态源；单个 Release 文档保留范围、验收方向和历史记录，不重复维护总体状态。

## 3. Release 退出标准

- 版本范围内 P0 Backlog 全部 Done。
- 对应后端编译、OpenAPI 导出、前端构建和必要接口抽样通过。
- 验收清单和发布运维文档已回填结果。
- 真实外部 Provider 的环境限制和复测项已记录为发布风险或后续任务。

## 4. 当前发布风险

- V1.7 本地验证已通过，但真实 Provider 网络级复测仍需在目标测试或预生产环境执行，并回填到正式发布记录或发布运维手册。
- V1.8 的 Sprint 30-34 已完成最小后端链路、管理端入口、App Runtime 安全边界设计、真实 Provider 轻量网络级复测、SSE streaming、应用级限流配额、调用统计、反馈回流和架构预留评估；切换测试或预生产环境后仍需重新执行真实 Provider 网络级复测。
