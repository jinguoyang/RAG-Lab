# 迭代计划 Sprint 31

## 1. Sprint 基本信息

- Sprint 名称：Sprint 31
- Sprint 主题：RAG App 管理端与调用可见性
- 涉及 Epic：E25 RAG 应用化封装
- 建议版本：V1.8
- 时间范围：待定
- 目标：在 Sprint 30 后端最小链路基础上，补齐 P13 RAG 应用管理入口，让知识库负责人可以创建应用、管理 App API Key、查看调用记录和会话摘要，并跳转回 QARun 做内部诊断。
- 开发计划：[RAG App Management UI Implementation Plan](../../plans/2026-05-15-rag-app-management-ui.md)

## 2. 关键假设

- 后端已提供 RAG App 管理、API Key 创建/撤销、调用记录列表和 App Runtime blocking 接口。
- 本 Sprint 只做管理端可见性和操作闭环，不实现 SSE streaming、限流配额、反馈回流或应用级 Prompt 模板。
- API Key 明文只在创建响应中展示一次；列表和详情只展示 `keyPrefix`、状态和时间。
- 调用明细只展示外部调用审计摘要；完整 Trace、Evidence 和 Candidate 仍跳转到内部 QARun 页面查看。

## 3. 本 Sprint 目标

- 新增 P13 RAG 应用管理页入口。
- 支持应用列表、创建应用、编辑名称/描述/状态/默认配置版本。
- 支持 API Key 列表、创建、一次性明文展示和撤销。
- 支持调用记录列表、会话摘要和关联 QARun 跳转。
- 补充前端服务、适配器和最小验证脚本，保证页面字段与 OpenAPI 契约一致。

## 6. 验收标准

- 用户可以从平台或知识库上下文进入 P13 RAG 应用管理页。
- 用户可以创建应用并绑定知识库和默认配置版本；未指定默认配置时清楚显示“跟随知识库 active revision”。
- 用户可以生成 App API Key，明文只在创建成功弹窗显示一次，关闭后页面不再保留明文。
- 用户可以撤销 Key，撤销后列表状态更新，Runtime 调用应由后端返回 `APP_API_KEY_INVALID`。
- 用户可以查看调用记录，看到状态、错误码、延迟、conversationId、messageId、qaRunId，并可跳转到关联 QARun。
- 页面在空列表、加载中、接口错误、无权限时都有明确状态。

## 7. 范围边界

- 不实现 App Runtime SSE streaming。
- 不实现应用级限流、配额、统计图表或审计导出。
- 不实现外部反馈回流。
- 不新增复杂应用级 Prompt 模板；`inputs` 只保留为只读扩展字段说明。
- 不在前端保存或二次展示 API Key 明文。
