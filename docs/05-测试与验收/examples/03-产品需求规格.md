### 3.2 文档状态流转

```
草稿(Draft) → 审核中(Reviewing) → 已发布(Published) → 已归档(Archived)
                    ↓
                已拒绝(Rejected) → 草稿(Draft)
```

| 状态 | 说明 | 可执行操作 |
|------|------|------------|
| Draft | 草稿状态 | 编辑、提交审核、删除 |
| Reviewing | 审核中 | 审核通过、审核拒绝 |
| Published | 已发布 | 查看、评论、归档 |
| Archived | 已归档 | 查看、恢复 |
| Rejected | 已拒绝 | 编辑、重新提交 |
