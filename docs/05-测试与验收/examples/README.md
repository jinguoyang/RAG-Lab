# RAG 测试数据集

## 概述

本数据集用于测试 RAG（检索增强生成）系统的多格式文档处理能力。所有文件围绕"智云协同办公平台 V3.0"项目主题，内容相互关联，包含丰富的表格数据。

## 测试场景建议

### 1. 跨文档检索测试

**问题示例**：

- "张明远负责哪些工作？"
- "项目使用了什么技术栈？"
- "Sprint 4 的任务完成情况如何？"

**预期**: 能从多个文档中检索到相关信息并整合回答

### 2. 表格数据查询测试

**问题示例**：

- "赵晓峰的技术栈是什么？"
- "BUG-045 的状态是什么？"
- "用户服务的端口号是多少？"

**预期**: 准确从表格中提取特定单元格数据

### 3. 关联推理测试

**问题示例**：

- "AI服务的负责人是谁？他的联系方式是什么？"
- "文档协作模块有哪些未修复的缺陷？"
- "前端负责人在会议中汇报了什么内容？"

**预期**: 能关联多个文档进行推理回答

### 4. 时间线查询测试

**问题示例**：

- "项目的里程碑时间安排是什么？"
- "第五次迭代什么时候结束？"
- "性能测试计划什么时候开始？"

**预期**: 准确提取时间相关信息

### 5. 多格式混合查询测试

**问题示例**：

- "系统架构图中有哪些服务？"（图片）
- "项目进度表中 Sprint 4 的完成率是多少？"（Excel）
- "会议纪要中讨论了哪些技术难点？"（TXT）

**预期**: 能处理不同格式的文档内容

## 生成脚本

Excel和图片文件由 [generate_test_files.py](generate_test_files.py) 生成，如需重新生成可运行：

```bash
python generate_test_files.py
```

依赖：

- openpyxl (Excel生成)
- matplotlib (图表生成)
- Pillow (图片处理)
