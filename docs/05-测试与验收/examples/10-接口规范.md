## 1. 接口规范

### 1.1 通用规范

| 项目 | 规范 |
|------|------|
| 协议 | HTTPS |
| 基础路径 | /api/v3 |
| 认证方式 | Bearer Token (JWT) |
| 请求格式 | application/json |
| 响应格式 | 统一包装 {code, message, data} |
| 时间格式 | ISO 8601 (UTC) |
| 字符编码 | UTF-8 |

### 1.2 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": "2026-05-20T06:30:00Z",
  "requestId": "req-uuid-12345"
}
```

### 1.3 错误码

| 错误码 | 说明 | HTTP状态码 |
|--------|------|------------|
| 200 | 成功 | 200 |
| 400 | 请求参数错误 | 400 |
| 401 | 未认证 | 401 |
| 403 | 无权限 | 403 |
| 404 | 资源不存在 | 404 |
| 409 | 资源冲突 | 409 |
| 429 | 请求过于频繁 | 429 |
| 500 | 服务器内部错误 | 500 |

### 1.4 分页参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| page | int | 1 | 页码，从1开始 |
| pageSize | int | 20 | 每页数量，最大100 |

分页响应：
```json
{
  "code": 200,
  "data": {
    "list": [],
    "pagination": {
      "page": 1,
      "pageSize": 20,
      "total": 100,
      "totalPages": 5
    }
  }
}
```

## 2. 用户模块接口

### 2.1 用户注册

| 属性 | 值 |
|------|-----|
| 路径 | POST /api/v3/users/register |
| 认证 | 不需要 |
| 负责人 | 赵晓峰 |

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 用户名，3-50字符 |
| email | string | 是 | 邮箱地址 |
| password | string | 是 | 密码，8-128字符，需包含大小写和数字 |
| departmentId | long | 否 | 部门ID |

**响应示例：**
```json
{
  "code": 200,
  "data": {
    "id": 1001,
    "username": "zhangsan",
    "email": "zhangsan@zhiyun.com",
    "createdAt": "2026-05-20T06:30:00Z"
  }
}
```

### 2.2 用户登录

| 认证 | 不需要 |

**请求参数：**

|------|------|------|------|
| username | string | 是 | 用户名或邮箱 |

## 5. AI模块接口

### 5.1 智能问答

| 属性 | 值 |
|------|-----|
| 路径 | POST /api/v3/ai/chat |
| 认证 | 需要 |
| 负责人 | 李建国 |

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| question | string | 是 | 用户问题 |
| context | string | 否 | 上下文信息 |
| stream | boolean | 否 | 是否流式响应，默认false |

**流式响应（SSE）：**
```
data: {"type": "token", "content": "智"}
data: {"type": "token", "content": "云"}
data: {"type": "token", "content": "协同"}
data: {"type": "done", "usage": {"promptTokens": 100, "completionTokens": 50}}
```

### 5.2 文档摘要

| 属性 | 值 |
|------|-----|
| 路径 | POST /api/v3/ai/summarize |
| 认证 | 需要 |
| 负责人 | 李建国 |

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| documentId | long | 是 | 文档ID |
| maxLength | int | 否 | 摘要最大长度，默认500字 |
